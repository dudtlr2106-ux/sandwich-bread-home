# KOCOM RS485 Protocol Registry

> 안전 규칙: **이 문서에서 `CONFIRMED` 상태인 패킷만 Edge Driver에 구현할 수 있습니다.**  
> 현재 확인된 raw packet은 **0개**이며, 송신은 금지합니다.

## 상태 정의

- `UNCONFIRMED`: 추정/관찰 단계. 구현 및 송신 금지.
- `CAPTURED`: 실제 버스에서 캡처했지만 의미 또는 체크섬 검증 전. 송신 금지.
- `VERIFIED`: 반복 관찰로 의미를 확인했으나 실제 송신 검증 전. 송신 금지.
- `CONFIRMED`: 주소/명령/데이터/체크섬과 실제 동작을 모두 검증. 구현 가능.

## Packet registry

| 기능 | 방향 | 예시 패킷 | 체크섬 | 상태 | 검증 메모 |
|---|---|---|---|---|---|
| 조명 ON/OFF | - | - | - | UNCONFIRMED | 실제 RS485 캡처 필요 |
| 난방 설정온도 | - | - | - | UNCONFIRMED | 실제 RS485 캡처 필요 |
| 환기 OFF/약/중/강 | - | - | - | UNCONFIRMED | 실제 RS485 캡처 필요 |
| 콘센트 ON/OFF | - | - | - | UNCONFIRMED | 실제 RS485 캡처 필요 |
| 엘리베이터 호출 | - | - | - | UNCONFIRMED | KOCOM 월패드 호출 전후 수신 캡처 필요 |

## 패킷을 CONFIRMED로 올리기 위한 체크리스트

1. 동일 명령을 여러 번 수행해 요청 패킷이 반복되는지 확인.
2. 장치/방/채널 주소 바이트를 분리해 확인.
3. ON/OFF 또는 설정값 변화에 따라 변경되는 데이터 바이트 확인.
4. 체크섬 또는 CRC 계산식을 재현.
5. 상태 응답 패킷과 요청 패킷을 구분.
6. 송신 전 테스트 환경에서 충돌/에코/재전송 조건 검토.
7. 실제 장치 1개를 대상으로 최소 명령부터 제한적으로 검증.
